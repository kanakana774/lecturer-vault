> `02_問題` と `04_解答` の両方が対象。

## 使い方

1. **「指示」列が空の行は、まだ何もしていない。** ユーザーが指示を書いてから Claude が直す。
2. 直したら「状態」を `済` にして、日付を入れる。
3. **テストデータを触る対処を選んだときは、必ず [[08_結合から使用するテーブル#依存関係表]] を見て、他の章への波及を確認する。**

## 分類

| 記号 | 意味 |
| :--- | :--- |
| **実測ズレ** | 資料に載っている出力・数値が、いま流すと違う値になる |
| **狙い不発** | 問題が見せたい現象が、現テストデータでは起きない |
| **導出不能** | 問題文からその解答は導けない（解答が問題文に無い前提を置いている） |
| **弁別力なし** | 素朴な誤答でも正解と同じ結果が出る。解いても手応えが無い |
| **解答の瑕疵** | 解答SQL・解説そのものが要求を満たしていない／誤っている |
| **順序不定** | `ORDER BY` が足りず、結果順が実行ごとに変わりうる |

## 深刻度

**高** = 問題として成立していない／解答が誤り ／ **中** = 出力の数値がズレている ／ **低** = 表記ゆれ・許容範囲
