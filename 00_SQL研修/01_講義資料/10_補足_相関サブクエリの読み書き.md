# 補足：相関サブクエリの読み書き

[[00_SQL研修/01_講義資料/10_サブクエリ|10_サブクエリ]] §2 で、相関サブクエリの3つの形を見ました。
ここでは形を並べ直すのではなく、**読むときの手続き**と**書くときの手続き**を1つずつ置きます。

使うテーブルは本編 §0 と同じ11テーブルです。

---
## 1. 規則は1つだけ

**外側の行を1つ固定し、その値を内側に差し込んでから、内側を実行する。**
相関サブクエリで起きているのは、最初から最後までこれだけです。

```
外側 products p1 の現在行: (Laptop, 1200.00, category_id = 1)
                                                    │
                                     差し込む       │
                                                    ▼
   (SELECT MAX(p2.price) FROM products p2 WHERE p2.category_id = 1)
                                                    │
                                     1200.00 を返す │
                                                    ▼
                          外側の条件 WHERE 1200.00 = 1200.00 → TRUE
```

**外側の行が決まらないと差し込む値が決まらないので、内側だけを取り出しても実行できません。**
非相関との分かれ目はここでした（→ 本編 §2 冒頭）。

読むときも書くときも、この1行に戻ります。

---
## 2. 読む — 外側の行を1つずつ固定する

### 2-1. 手順

1. **外側の行を1つ選ぶ**
2. **相関条件の列を、その行の値に書き写す。** 内側が単独で実行できる形になる
3. **内側を実行し、結果を外側の条件に戻す**

題材は本編 §2-2「各カテゴリで最も価格が高い商品」です（再掲）。

```sql
SELECT p1.category_id, p1.product_name, p1.price
FROM products AS p1
WHERE p1.price = (
  SELECT MAX(p2.price)
  FROM products AS p2
  WHERE p2.category_id = p1.category_id
)
ORDER BY p1.category_id, p1.product_name;
```

### 2-2. 1行目を実際に固定する

外側の1行目は `Laptop`（`category_id = 1`、`price = 1200.00`）です。
相関条件 `p2.category_id = p1.category_id` の右辺を、手で `1` に書き写します。

```sql
SELECT MAX(p2.price)
FROM products AS p2
WHERE p2.category_id = 1;
```

```
   max
---------
 1200.00
(1 row)
```

この `1200.00` が外側に戻り、`WHERE 1200.00 = 1200.00` → `TRUE` なので `Laptop` は結果に入ります。

**読めないクエリに出会ったら、この形に書き直して実際に実行してください。**
相関条件を手で値に置き換えるだけで、単独で動くただのサブクエリになります。

## 3. 書く — 2つ決めれば形が決まる

### 3-1. 3つの形は、2軸の升目

3つを別々に覚える必要はありません。決めることは2つだけです。

- **内側に何を聞くか** … 有無か、値か
- **その答えをどこで使うか** … 行を絞るか、列として出すか

|  | `WHERE` で絞る | `SELECT` で列にする |
| :--- | :--- | :--- |
| **有無を聞く** | `EXISTS` / `NOT EXISTS`（→ 本編 §2-1・§3-3） | `EXISTS (...)` をそのまま列に（→ §3-3） |
| **値を聞く** | 比較演算子（→ 本編 §2-2） | スカラーサブクエリ（→ 本編 §2-3） |

本編で扱ったのは左上・左下・右下の3つです。**残る右上も、新しい構文なしで書けます。**

### 3-2. 組み立ては外側から

1. **主役を決める。** 出したい行が並ぶテーブルが外側になる
2. **外側の1行に対して何を聞くか、日本語で書く。** 「この顧客に注文はあるか」「この商品のカテゴリの最高価格は」
3. **内側を、外側を忘れて書く。** `WHERE category_id = 1` のような**具体値**で書いて、単独で動かす
4. **具体値を相関条件に戻す。** `= 1` を `= p1.category_id` に置き換える

**3 を飛ばさないでください。** 内側が単独で動くことを確かめる前に相関条件を書くと、
外と内のどちらが壊れているのか分からなくなります。§2 の読み方を逆にたどっているだけです。

### 3-3. 4つ目の升目 — 有無を列にする

> **【お題】** 顧客一覧に、注文があるかどうかを列で併記する

```sql
SELECT
  c.customer_id,
  c.name,
  EXISTS (
    SELECT 1
    FROM orders AS o
    WHERE o.customer_id = c.customer_id
  ) AS 注文あり
FROM customers AS c
ORDER BY c.customer_id;
```

```
 customer_id |  name   | 注文あり
-------------+---------+----------
           1 | Alice   | t
           2 | Bob     | t
           3 | Charlie | f
           4 | Diana   | t
           5 | Ellen   | t
           6 | Grace   | f
           7 | Hank    | t
           8 | Ivy     | t
           9 | Jack    | t
          10 | Kevin   | t
          11 | Leo     | t
(11 rows)
```

**`EXISTS (...)` は `TRUE` / `FALSE` を返す式です。**
`WHERE` に置けば絞り込みになり、`SELECT` に置けばそのまま列になります。
本編 §2-1 で全員を絞り込んだのと、ここで全員を残して印を付けたのは、同じ式の置き場所が違うだけです。

---
## 4. 升目の外に出たとき

置ける場所は `WHERE` と `SELECT` だけではありません。たとえば `ORDER BY` にも書けます。

```sql
SELECT c.name
FROM customers AS c
ORDER BY (
  SELECT COUNT(*)
  FROM orders AS o
  WHERE o.customer_id = c.customer_id
) DESC, c.customer_id;
```

注文が4件の `Alice` が先頭、3件の `Bob`、2件の `Diana` と続き、注文が0件の `Charlie` と `Grace` が最後に並びます。
**列として出さずに、並べ替えにだけ使った形**です。

**場所が変わっても §1 の規則は変わりません。**
知らない形に出会ったら、外側の1行を固定して、§2-2 のように相関条件を手で値に書き写してください。
そこから先は、ただのサブクエリです。
