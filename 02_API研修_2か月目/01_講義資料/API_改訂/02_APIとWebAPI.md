# API と Web API

> [!abstract] この章が終わったら
> - **API** が何かを、身近な例で説明できる
> - **Web API** が普通の API と何が違うかを説明できる
> - 公開されている Web API を**自分で叩いて**、返ってきたデータを見たことがある

---

## 1. API とは「窓口」である

**API（Application Programming Interface）** とは、**ソフトウェアの機能を外から使うための窓口**です。

1 か月目に `List` を使ったときを思い出してください。

```java
list.add("hoge");
```

このとき、`add()` の中でメモリがどう確保されているかを調べましたか。調べていないはずです。
それでも使えたのは、**「`add()` を呼べば要素が追加される」という約束（規格）が決まっていた**からです。

この「**中身を知らなくても、決められた呼び方さえ守れば使える**」という仕組みが API です。

> [!hint]- 身近な例
> スマートフォンで電話をかけるとき、iOS か Android かをいちいち意識しないはずです。
> 「通話ボタンを押せば電話がかかる」という操作の型が決まっているからです。
> 中の仕組みを知らなくても、使い方さえ知っていれば使える——これも一種の窓口です。

**中身を知らなくていい**ということは、**中身が変わっても使う側は困らない**ということでもあります。
`add()` の内部実装が改善されても、`list.add("hoge")` という書き方は変わりません。

---

## 2. Web API ＝ インターネット越しの窓口

`List` の例は、**同じプログラムの中**での呼び出しでした。
これを**インターネット越し**に広げたものが **Web API** です。

| | 普通の API | Web API |
| :--- | :--- | :--- |
| 呼ぶ相手 | 同じプログラムの中のクラス | **別のコンピューター（サーバー）上のプログラム** |
| 呼び方 | メソッド名と引数 | **URL とデータ形式** |
| 何で繋がるか | プログラムの中 | **HTTP**（次章） |
| 返ってくるもの | 戻り値のオブジェクト | **JSON などのデータ** |

呼び方が「メソッド名」から「URL」に変わっただけで、
**「中身を知らなくても、決められた呼び方さえ守れば使える」という性質は同じ**です。

---

## 3. データだけ返すと、何が嬉しいのか

前章で「2か月目に作るのはデータだけを返す側」と書きました。改めて理由を整理します。

- **受け取る側を選ばない** — ブラウザでも、スマホアプリでも、他社のシステムでも、同じ窓口を使える
- **画面と切り離せる** — 画面のデザインを作り直しても、データを返す側はそのまま使える
- **自分で作らなくていい機能が増える** — 地図、天気、決済。自社で作りきれない機能を、
  公開されている Web API を呼ぶだけで組み込める

---

## 4. 公開されている Web API を叩いてみる

実際に、世界中に公開されている天気予報の Web API を呼んでみます。

**仕様書（＝窓口の使い方が書いてある）**
https://openweathermap.org/api

**呼び方**

```
http://api.openweathermap.org/data/2.5/forecast?q={都市}&appid={APIキー}&lang=ja&units=metric
```

```bash
curl "http://api.openweathermap.org/data/2.5/forecast?q=Tokyo,JP&appid={APIキー}&lang=ja&units=metric"
```

> [!example]- 講義中にやること
> - 実際に叩いて、**JSON が返ってくる**ところを見る
> - `q=Tokyo,JP` を別の都市に変えて、返る中身が変わることを見る
> - **APIキーは講義中に共有します。**

ここで見てほしいのは次の 2 点です。

1. **URL を送っただけで、データが返ってきた** — 相手のプログラムがどう書かれているかは一切知らない
2. **返ってきたのは画面ではなくデータ** — このデータをどう見せるかは、呼んだ側の自由

**2か月目に作るのは、この「叩かれる側」です。**
todo 管理のデータを、決められた URL で受け取って返すプログラムを作ります。
