## Todo を分類する Tag を扱う機能

- Tag のリソースを操作する機能。
- Todo との紐づけ(Todo_Tag)の登録・更新は Todo 機能側で行う。

### Tag の一覧取得

1. バリデーションチェック
   - 特になし

2. 入力値に関する処理

   2-1. 以下の情報を受け取る
   - `name`(検索対象の Tag 名、クエリパラメータ、任意)

   2-2. 情報をサービス層に渡す

3. ビジネスロジック

   3-1. Tag 情報の取得処理
   - 取得した結果が 0 件の場合
     - 空のリストを取得
   - 取得した結果が 1 件以上の場合
     - 取得した Tag 情報リストを保持

4. 画面へ情報を渡す

   取得した Tag 情報リストとステータスコード(200)を返却

---

### Tag の登録

1. バリデーションチェック
   - `name`が未入力を満たす場合
   - `name`が 1 文字以上 30 文字以内の指定を超えている場合を満たす場合
   - 上記いずれかを満たす場合、ステータスコード(400)の例外をスロー

2. 入力値に関する処理

   2-1. 以下の情報を受け取る
   - `name`

   2-2. 情報をサービス層に渡す

3. ビジネスロジック

   3-1. Tag の登録処理
   - 登録した Tag の`tag_id`を取得

4. 画面へ情報を渡す

   登録した Tag の TagId とステータスコード(201)を返却

---

### Tag の 1 件取得

1. バリデーションチェック
   - 特になし(パスパラメータの`tagId`のみを受け取る)

2. 入力値に関する処理

   2-1. 以下の情報を受け取る
   - `tagId`(パスパラメータ)

   2-2. 情報をサービス層に渡す

3. ビジネスロジック

   3-1. Tag の存在チェック
   - 取得した結果が 0 件だった場合
     - ステータスコード(404)の例外をスロー
   - 取得した結果が 1 件だった場合
     - 取得した Tag 情報を保持

4. 画面へ情報を渡す

   取得した Tag 情報とステータスコード(200)を返却

---

### Tag の更新

1. バリデーションチェック
   - `name`が未入力を満たす場合
   - `name`が 1 文字以上 30 文字以内の指定を超えている場合を満たす場合
   - `version`が未入力を満たす場合
   - 上記いずれかを満たす場合、ステータスコード(400)の例外をスロー

2. 入力値に関する処理

   2-1. 以下の情報を受け取る
   - `tagId`(パスパラメータ)
   - `name`
   - `version`

   2-2. 情報をサービス層に渡す

3. ビジネスロジック

   3-1. Tag の存在チェック
   - 取得した結果が 0 件だった場合
     - ステータスコード(404)の例外をスロー

   3-2. Tag の更新処理
   - `tagId`と`version`を条件に Tag を更新し、更新件数を取得

   3-3. 楽観ロックチェック
   - 更新件数が 0 件の場合(`version`が最新でない場合)
     - ステータスコード(409)の例外をスロー

4. 画面へ情報を渡す

   ステータスコード(204)を返却

---

### Tag の 1 件削除

1. バリデーションチェック
   - `version`が未入力を満たす場合
     - ステータスコード(400)の例外をスロー

2. 入力値に関する処理

   2-1. 以下の情報を受け取る
   - `tagId`(パスパラメータ)
   - `version`

   2-2. 情報をサービス層に渡す

3. ビジネスロジック

   3-1. Tag の存在チェック
   - 取得した結果が 0 件だった場合
     - ステータスコード(404)の例外をスロー

   3-2. Tag の削除処理
   - `tagId`と`version`を条件に Tag を 1 件物理削除し、削除件数を取得

   3-3. 楽観ロックチェック
   - 削除件数が 0 件の場合(`version`が最新でない場合)
     - ステータスコード(409)の例外をスロー

4. 画面へ情報を渡す

   ステータスコード(204)を返却
