# 13_議事録

**AI研修の方針を決めた打ち合わせの記録。MTG ごとに1ファイル貯める。**

## 約束

| | |
|---|---|
| **ファイル名** | `YYYY-MM-DD_相手.md` |
| **指摘は言われたまま残す** | **要約しない。**あとで「そういう意味だったのか」と読み返すため |
| **決まったことは正本へ溶かす** | 設計原則 → `06_研修の芯.md` ／ 流れ → `12_研修の流れ_説明用.md` ／ 具体 → `07_実施計画.md` |
| **議事録には「経緯」を残す** | **なぜそう決めたか。**正本には結論しか書かないので、迷った跡はここにだけ残る |

**議事録は更新しない。** MTG後に決まったことは「その後の決定」節に日付つきで足す。**前の記述を書き換えない。**
