## 1-4 Q&A票の雛形

| # | AIが挙げた項目 | AIが示した根拠 | 判定 | 自分が書くこと |
|---|---|---|---|---|
| 1 | | | ①／②／③／未判定 | |
| 2 | | | ①／②／③／未判定 | |

| 判定 | 「自分が書くこと」に何を書くか |
|---|---|
| **① 書いてあった** | **資料名と場所**（例: `Todo機能.md` の「Todo の更新」3-4） |
| **② 空白・自分で決められる** | **こう決めた ＋ その理由** |
| **③ 空白・自分では決められない** | **誰に聞くか ＋ 何を聞くか** |
| **未判定** | 手をつけていない理由（**空欄にしない**） |

**迷ったら③。** ／ **⚠ 制約が無いこと・書かれていないことを、「許可」や「決定済み」として読まない。**
