# 10_シミュレーション — 研修を1周分、紙の上で回す

**目的は疎通と抜け漏れの検出。** **入力と出力だけ**を置く。

| ファイル | 中身 |
|---|---|
| `NN_<段名>_渡すもの.md` | 作業ごとの**入力**（現物だけ） |
| `NN_<段名>_出てくるもの.md` | 作業ごとの**出力**（実測＋想定）＋**講師の指摘欄** |

**手順・時間・講師の動きは `07_実施計画.md` が正本。** ここには置かない（`やること.md` は二重管理になるので廃止）。
**2ファイルは作業番号（`段-連番`）で対応する。** 見せ方は **07 の作業表を開いたまま** `渡すもの1-2 → 出てくるもの1-2 → 渡すもの1-3 → …`

## 約束

- **AIの出力は実測。** 実際に走らせた結果を貼る。「AIはこう言うだろう」で書かない
- **研修生の判断は想定。** 3か月目終わりの新人役で書き、**失敗を混ぜる**
- **根拠・判断の経緯はここに書かない。** 正本は `07_実施計画.md`（具体）と `06_研修の芯.md`（原則）
- **教材の不備の一覧もここに書かない。** 正本は `04_教材見直しの材料.md`
