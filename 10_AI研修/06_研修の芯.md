# AI研修の芯 — 設計原則

> **この一枚は滅多に更新しない。太らせない。**
> 具体（時間割・材料・提出物・工数）は `07_実施計画.md`。網羅性の裏取りは `08_AI開発の一般的手法とのギャップ.md`。探索の記録は `00`〜`05`。

---

## 目的（一文）

> ### AIで作ったものを、自分の名前で出せるようにする。

SES では客先に**自分の名前で**成果物を出す。AIが書いたものでも変わらない。

---

## 構造 — 入口／中／出口

```
入口（自分）→ 中（AI）→ 出口（自分）
```

実装が速くなった分、価値は**入口（何を作るか）と出口（保証できるか）**に移った。
**新人の仕事が上流に「昇格」するのではなく、同じ職位・同じ担当のまま、仕事の中身が入口と出口に寄る。** だから配属直後の新人にこそ先に来る。

---

## 6つの段

| | 段 | 目的（到達した状態） | 代表語 |
|---|---|---|---|
| 前提 | **⓪ ガバナンス** | **使ってよいかを、自分で判断できる** | NDAと第三者開示／コピーレフト |
| **入口** | **① 把握** | **何が決まっていないかを、分かっている** | 要件の把握／AIの誤検出 |
| **入口** | **② 決定** | **決めることと、聞くことを、着手前に仕分けている** | 受入基準／完了の定義（DoD） |
| 中 | **③ 委任** | **任せた仕事の流れが、見えている** | ステップ承認／テストを仕様から書く |
| **出口** | **④ 検証** | **動いた、ではなく、正しいと言える** | 動いた≠正しい／ハルシネーション |
| **出口** | **⑤ 提出** | **自分の名前で出せる。出せない部分は、出せないと言える** | 説明責任／エスカレーション |

**①は「気づく」、②は「決める」。** 同じ「仕様を読む」作業に見えるが、発見と決定を分けている。

## 到達ライン

| | |
|---|---|
| **3か月（この研修が狙う）** | **チケット1本を、AIを使って、自分で確認して出せる。** 保証できない部分を「判断できないので確認したい」と**言える**。**独断しないことが合格条件**で、判断の広さは求めない |
| 1年 | 曖昧なチケットを**自分で整えられる**。渡すコンテキスト（指示ファイル・テスト）を育てられる。保証できる範囲が広がる |

## 設計原則

1. **目的は「到達した状態」で書く。作業を書かない。** そのまま評価の文になる。「〜する」で書くと達成したか判定できない
2. **答えを配らない。** 検証に唯一の答えは無く、**講師にも無い**。だから **添削はしない／評価はする／議論はする** の3つを分ける
3. **失敗を仕込まない。** わざと情報を抜いて失敗させる演習は作らない。作為的で、AIが賢くなると成立しなくなる
4. **陳腐化するものを軸にしない。** ツール操作・プロンプト技法・モデル比較は**触るだけ**
5. **新しく教える技術をゼロにする。** 道具は全部既習（`git diff`・テスト仕様書・レビュー観点・PR）。**新規はAIへの一文だけ**
6. **提出して終わる成果物を作らない。** 各段の提出物が次の段の入力になる
7. **実装するのはAI。研修生がやるのは委任。** だから③を「実装」と呼ばない

---

## 軸にしないもの

| | 扱い |
|---|---|
| ツールの操作 | 触るだけ（半年で陳腐化する） |
| プロンプトの工夫 | **講師が配る。**研修生に考えさせない |
| コンテキストの与え方 | **経験の中で自得させる。**教える項目にしない |
| モデル比較・コスト最適化 | 扱わない（新人の裁量外） |
| **自分の成長を守る判断**（任せる／自分でやる） | **演習にしない。**最後に一言で伝える。本人の判断だが、面接で語れる強い材料 |

---

## この構成が崩れない理由

- **フェーズ非依存** — ガバナンスと検証は陳腐化しない。委任は「一周回した」事実が残る
- **ツール非依存** — 伝え方は抽象、触るのは具体。**「これはツール固有／これは普遍」をその場で言い分ける**
- **既存カリキュラムに接続** — Git（差分）／PR・レビュー（明示）／テスト仕様書からのケース洗い出し（突き合わせ）
- **AI禁止の現場でも残る** — 客先ルールの確認・仕様を読む力は、AIの可否と無関係
- **講師のAI習熟度に品質が依存しない** — 答えを配らない設計の帰結。講師の知識更新に研修の質が依存しない
